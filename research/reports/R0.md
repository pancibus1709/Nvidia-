# R0 report: setup and scope

**Date:** 23 November 2026

## Built

| Piece | File | What it does |
|---|---|---|
| SEC client | `pipeline/edgar.py` | Declared contact from the environment, 8 requests per second across all processes, every response cached with its retrieval time |
| Source cache | `pipeline/cache.py` | Fetches allowlisted domains only; text search with offsets |
| Evidence tool | `pipeline/evidence.py` | Writes a citation only if the quote is found verbatim in the cached source and the number sits in or near it. Adds a link that opens the source at the passage |
| XBRL reader | `pipeline/xbrl.py` | Time series for any tagged concept, to cross-check the text |
| Section extraction | `pipeline/extract.py` | Notes, sections, risk factor comparison filing over filing, exhibit lists |
| Full-text sweep | `pipeline/fulltext.py` | Queries Q1 to Q12, fifty-word window filter, overflow splitting |
| 13F parser | `pipeline/thirteenf.py` | Holdings by quarter with new, changed and exited positions |
| Checks | `pipeline/checks.py` | Every automated check in spec/09 |
| Measures | `pipeline/measure.py` | Gross exposure, EAD, derived measures, significance |
| Scenarios | `pipeline/scenarios.py` | S1 to S3 |
| Schemas and enums | `schema/` | One schema per record type, enums defined once |
| Configs | `config/` | Source allowlist, grade rubric, draw rates, scenarios, significance, staleness, banned words |

## Tests

`make test`: 29 fixture tests pass. They prove the checks reject a quote that is not in the source, a changed source file, a number that is not near its quote, a single-source figure, two sources with one parent company, an excluded domain, a headline counted as exposure, an unattributed remainder counted in a total, a typed number in an insight, a dash in text we write, and a consequence that names no counterparty. A filing quote containing an en dash passes. A negative demand shock produces a backstop draw greater than zero that equals an independent calculation.
